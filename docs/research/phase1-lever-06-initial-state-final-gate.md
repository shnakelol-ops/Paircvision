**Status:** Final gate, September 2026. **Where either Lever 06 audit and this gate differ, this gate governs PáircVision V1.**

> **Central question.** Does INITIAL STATE manipulate something distinct enough to be a PáircVision practice-design lever, or is it scenario selection plus SPACE × NUMBERS × TIME × DIRECTION?
>
> **Chain kept separate throughout:** SELECTED GAME MOMENT → SUPPLIED INITIAL CONDITIONS → EXPERIENCED PROBLEM → PLAYER RESPONSE → RECOGNITION → SELF-CREATED SOLUTION → LEARNING → RETENTION → TRANSFER.
>
> **Standing rules:**
> - Practice behaviour ≠ learning.
> - Absent transfer evidence means transfer is **unknown**, not absent.
> - We are willing to kill the lever.

## 1. Reopen the name

| Name | What it implies | Precision |
|---|---|---|
| STARTING POSITIONS | Where players stand | **Too narrow.** Positions are an implementation method (§5) |
| INITIAL STATE | Everything true at t0 | **Too broad.** It absorbs configuration that belongs to frozen levers |
| START STATE | As above | Same problem |
| SCENARIO | A situation, often with story (score, time, opponent) | **Too loose.** It mixes game moment with INFORMATION (score / time) and rehearsal scripts |
| GAME-MOMENT SAMPLING | Which moments, how often | Precise for **frequency**, but it names only one component |
| **GAME MOMENT** | Which situation of the game an episode begins from | **Most precise description of what the coach chooses** |

**Candidate tested:** *The coach chooses which game state an episode begins from, how that state is generated, and how frequently different states are sampled.*

| Component | Attack | Survives in… |
|---|---|---|
| "which game state" | "State" invites configuration detail; "moment" (turnover, kickout, loose ball…) is what coaches actually choose | **GAME MOMENT** |
| "how that state is generated" (coach-supplied vs emergent) | Changes whether **recognising** the moment is part of the task. That is a property of the **signal source**, which DIRECTION already assigned to INFORMATION (coach call vs game event), plus a cross-framework agency principle | **INFORMATION + cross-framework principle** (§7) |
| "how frequently sampled" | A property of the **practice programme**, not of the task players experience | **GAME MOMENT** as an exposure decision (§2) |

**Chosen name: GAME MOMENT.** It is the least sophisticated and the most literal.

---

## 2. Is sampling actually a constraint lever?

**The threat.**
- SPACE, NUMBERS, TIME, DIRECTION and SCORING **alter properties of a task** players experience.
- Choosing *turnover* vs *kickout* vs *loose ball* **selects which task occurs**.
- Choosing how often each occurs is **scheduling**.

**Adjudication.**
- **Choosing the game moment is not a constraint on a task.** It is a **task-selection / exposure decision**: which problem is practised, and in what proportion.
- It sits at a **different conceptual level** from the five frozen levers. The frozen levers modify a problem; GAME MOMENT chooses the problem.
- **Consequence.**
  - GAME MOMENT should not be listed as "Lever 06" in the same family as SPACE–SCORING.
  - It is a **practice-design decision of a different type** (§21–22).

## 3. The McKay case: stress test

**Source:** McKay & O'Connor (2018), *International Sport Coaching Journal* 5(3):273. Abstract and index only.

| Question | What accessible evidence shows |
|---|---|
| What was measured? | Queensland Reds possession sources in Super Rugby (2010–13 campaigns). ~48 possessions per game: ~27 from **offensive transition** (kick receipt, turnovers from errors, quick-tap penalties) and ~21 from **offensive organisation**. So ~56 % came from transition (AO / SIO) |
| What changed in training? | The attack coach "incorporated constraint-based activities … to represent game-related scenarios". A "high proportion of playing-form activities related to unstructured possession sources" was recommended (AO) |
| Were starts constructed? | **Likely** (scenario activities representing possession sources). Exact generation (coach-triggered vs emergent) is **UNR** |
| Was frequency deliberately weighted? | Exposure to unstructured sources was deliberately **increased** because traditional practice under-represented them. Whether it was **matched** to match proportions is **UNR** |
| Outcomes reported | Two tries in the 2011 Super Rugby Grand Final were scored "in a manner that simulated the rehearsed game-related scenarios". **Anecdotal** |
| Causal learning / transfer established? | **No.** No control, no retention test, no isolation from other factors |
| INITIAL STATE, or representative practice design? | **Representative practice design at the level of exposure.** It chose **which moments** to practise more. It supports GAME MOMENT as a **selection** decision, not starting configuration as a constraint lever |

**Verdict.**
- The case shows that a credible coach used match-moment frequencies to **re-weight exposure**. That is a coherent practice-design logic.
- It is **one case** with anecdotal outcomes. **It must not define the taxonomy by itself.**

## 4. Three components

| | Component | What it is | Belongs together with the others? |
|---|---|---|---|
| **A** | GAME MOMENT | Which situation begins the episode | Core |
| **B** | GENERATION | How the situation arises: coach-supplied / scripted trigger / random trigger / emerges from play | **Different kind of thing.** It changes the **information** players must detect (whether the moment announces itself). It generalises across levers (supplied vs emergent) |
| **C** | SAMPLING | How often each moment is encountered | Same **level** as A (exposure decisions) |

**Split:**
- **A + C** = GAME MOMENT (what problems, how often).
- **B** leaves GAME MOMENT:
  - the **signal-source** aspect goes to INFORMATION (consistent with DIRECTION §2: a coach call is INFORMATION; a game event is DIRECTION polarity / game structure);
  - the **agency** aspect becomes a **cross-framework principle** (§7).

## 5. Starting configuration

| Configuration | Effect described by | Verdict |
|---|---|---|
| Player locations; width; depth | SPACE (relational / occupied space) | **Absorbed** |
| Defender distance; pressure distance | TIME (usable time) × SPACE | **Absorbed** |
| Local overload | NUMBERS (local vs global; GIVEN) | **Absorbed** |
| Head starts; chasers; delayed defenders | TIME (entry / recovery timing, frozen TIME family) × NUMBERS (temporary) | **Absorbed** |
| Ball location relative to players | SPACE × DIRECTION (field position); possession status belongs to GAME MOMENT | **Absorbed**, except possession status (which is part of the moment) |

**Candidate conclusion confirmed.**
- Configuration variables are **implementation methods** whose effects are already described by SPACE, NUMBERS, TIME and DIRECTION.
- Dyad research (initial distance, field location, posture) supports that they change behaviour acutely (SP-1). The **effects** are frozen-lever effects.
- "Starting positions" is **not retained**.

## 6. Body orientation

| Candidate home | Assessment |
|---|---|
| INITIAL STATE | Would be the only orphan variable justifying a lever. **Rejected as justification** |
| Player technique | When taught ("open body", "half-turn"), it is technique / instruction |
| Informational / perceptual condition | Orientation determines **what can be seen** and when. Its main effect is on information pickup (and usable time) |
| SPACE / DIRECTION relationship | Angle to the target is a relational variable (dyad research: angular relations regulate coordination) |

**Resolution.**
- A **starting** orientation is an initial value of a **perceptual / relational condition**.
- **Provisional home: INFORMATION** (what the player can see at t0), with relational effects under SPACE / DIRECTION.
- **Re-examine at the INFORMATION audit.** It does not justify a lever.

## 7. Supplied vs emergent: cross-framework, not a lever property

**Parallel findings across gates:**

| Gate | Supplied condition | Finding |
|---|---|---|
| NUMBERS (N6 / N7) | Given overload | Given ≠ recognised ≠ created ≠ exploited; transfer UNKNOWN |
| DIRECTION (DIR-4; H-2) | Mandated directional action | Obeying ≠ learning; mandates remove the decision |
| SCORING (SC-2) | Rewarded behaviour | More rewarded behaviour ≠ evidence of learning |
| Lever 06 (SP-3 / SP-9) | Supplied position; coach-called moment | Behaviour from a supplied picture ≠ ability to recognise or create it; placement removes positioning decisions |

**Verdict.**
- This is a **cross-framework principle** about **coach control and player agency**, not a property of any single lever.
- **Removed from the Lever 06 definition.**
- **Frozen as a PáircVision cross-framework principle (CF-1, §18).**

## 8. The transition test

| | Design | What players must do |
|---|---|---|
| A | Coach creates turnover start | Respond **after** possession changes |
| B | Turnover occurs naturally | **Perceive** that possession changed **and** respond |

**Candidate:** *Constructed transition may preserve the post-transition problem while removing transition recognition.*

- **By construction:** when the coach announces the turnover, the detection cue is **supplied**. The task no longer requires detecting it. This is logically true (as with DIRECTION H-2: a mandate removes a decision).
- **Consequence for learning** (whether recognition then goes untrained, or whether it matters): **no evidence**.
- **Practitioner position:**
  - McKay **constructed** transition starts, with anecdotal success.
  - USA Hockey and the FA favour **continuous** transitions.
  - **No practitioner explicitly separates perceiving from responding.**
  - Practitioner support is thin and partly contradicted.

**Label: PÁIRCVISION HYPOTHESIS.** The logical core is sound; the practical consequence is untested. **Not SUPPORTED.**

## 9. Restart exception

**Test:** *When competition prescribes a start, reproducing it may preserve representative information rather than remove it.*

| Assessment | |
|---|---|
| Logic | Sport-fixed starts (Gaelic kickouts, frees, sidelines, throw-ins; scrums / lineouts; corners; inbounds; face-offs; AFL stoppages) **are** real game states. Reproducing them samples the competition. Coach-constructed open-play starts never occur neatly in matches |
| Practitioner support | AFL manuals: set plays at dead-ball situations are "predictable structures" rehearsed in training. Gaelic: "structure over kickouts" (Nally). **No practitioner argues it explicitly in representativeness terms** |
| Evidence of greater learning / transfer | **None** |
| Current Gaelic rules | Kickout rules changed (secondary sources). **Official Guide text still unverified** (SCORING gate research debt) |

**Verdict: useful distinction; PÁIRCVISION HYPOTHESIS** (representative-design inference). **No claim of greater learning or transfer.**

## 10. Representative sampling

**Tested:** *Practise game moments in the same proportions they occur in matches.*

**Attack:**
1. **Match frequency ≠ ideal practice frequency.**
   - A rare but decisive moment (a last-minute kickout under a press) may deserve disproportionate practice.
   - A frequent moment may already be well learned.
   - A team weakness may justify oversampling.
2. **Representative learning design (Pinder et al., 2011)** asks that practice **sample** the information of performance. It does **not** prescribe proportional frequency (theory; AO).
3. **McKay** increased exposure to an **under-practised** frequent moment. That is re-weighting away from past practice habits, not proportional matching (as far as accessible).
4. **No study** compares sampling rules for learning or transfer.

**Verdict.**
- **"Practise in match proportions" is NOT a principle.**
- The defensible statement: **match frequency is one useful input to deciding what to practise; it is not a rule** (evidence status: no sampling rule is supported).

## 11. Frequency vs importance

| | Frequent | Rare |
|---|---|---|
| **Important** | e.g., turnovers, breaking ball | e.g., last-minute kickout under press; defending a late two-point attempt |
| **Low consequence** | e.g., routine recycling in own half | e.g., unusual restarts |

- **Possible sampling bases:**
  - frequency;
  - importance / consequence;
  - learning need (what players can't yet do);
  - tactical identity (game model);
  - upcoming opponent;
  - player weakness;
  - combinations.
- **Evidence:**
  - frequency-informed re-weighting (McKay; practitioner case);
  - game-model-driven selection (tactical periodisation; practitioner);
  - opponent mimicry (high-performance Gaelic coaches; research-described).
  - **No evidence compares bases for learning.**
- **No algorithm prescribed.**
- **PÁIRCVISION INTERPRETATION:** the choice is a **coach judgement** combining these bases. PáircVision can make the bases visible, not rank them.

## 12. Structure vs adaptation

- **Practitioner distinction (practitioner audit §19):**
  - structured rehearsal targets **shared team coordination** (tactical periodisation; restart set-ups);
  - less-prescribed starts target **individual / small-group perception and adaptation** (USA Hockey; Sarama; AIK).
- **Is it supported?**
  - It is a **coherent description of different stated aims** (practitioner-supported).
  - **No evidence** tests which approach achieves which aim.
- **"Structure bad / freedom good": REJECTED.**
  - Elite environments use heavy structure.
  - Restarts are legitimately rehearsed.
  - Introducing a new team structure may require supplied solutions.
- **Status: PRACTITIONER HEURISTIC.**

---

## 13. Age and expertise

- **Claim:** "More structure for young players, less for elite players."
  - **CONTRADICTED as a general principle.** Elite tactical environments are often highly structured. Youth constraints-led environments are often less structured.
  - **No evidence** establishes age-appropriate amounts of structure.
- **Strongest defensible wording:**

> **"How much structure a practice supplies seems to follow its purpose (team coordination, restart rehearsal, individual adaptation) more than the players' age. No evidence tells us the right amount for a given age or level."**

- Status: **PRACTITIONER HEURISTIC** (purpose) + **UNKNOWN** (age prescription).
- **Separate expertise from purpose.** Expertise may change how quickly players can use a structure. Purpose determines whether structure is being supplied at all.

## 14. Learning and transfer: final search

**Searched:** constructed tactical starting state → training → removal → free test or competition → retention / transfer.

**Closest item found:**
- A rugby pedagogy study: 14 teams of six, ages 15–21, elite training centres in France (SIO; **source UNR**).
- Constructed defensive scenarios were used in pre (12 plays), intervention (12 plays, 3 scenarios) and post phases (20 plays).
- The post phase included the 3 familiar scenarios **and 2 new defensive scenarios (transfer test)**.
- **What it does not do:**
  - It manipulated **pedagogical conditions**, not the starting state.
  - All phases used constructed starts.
  - The post-test was **same-session**.
  - Results are **UNR**.
- **Methodologically**, it shows how "same game moment, new configuration" transfer could be tested. **It is not evidence for GAME MOMENT effects.**

**Also:** Gonzalez-Artetxe et al. (reference-game rules study; SCORING gate) did not manipulate starts.

> **Does practising from a constructed tactical starting state improve recognition or solution of that state once the construction is removed, later, or in competition? UNKNOWN.**

## 16. Cross-framework principle: "A coach can supply the problem without supplying the solution"

| Aspect | Assessment |
|---|---|
| Evidence-supported? | **No direct evidence** that supplying only the problem improves learning |
| Practitioner-supported? | **Yes** (USA Hockey "finding, not giving, the solution"; Sarama; AIK), and **contested** (tactical periodisation; restart rehearsal) |
| PáircVision synthesis? | **Yes.** It organises SP-4 / ISP-2 and the supplied-vs-created findings |
| Too simplistic? | **Yes, if universal.** Supplying the solution is legitimate for: technical instruction; tactical rehearsal of a team model; restart coordination; introducing a new team structure; safety |

**Nuanced form (PÁIRCVISION HYPOTHESIS):**

> *"A coach can supply the problem without supplying the solution. Whether to supply the solution as well depends on the purpose: coordination and rehearsal may need it; recognising and creating solutions cannot be practised if it is always supplied."*

## 18. Final principles

**Reduction.** SP-1 to SP-9 and ISP-1 to ISP-7 reduce to three GAME MOMENT principles plus one cross-framework principle.

| # | Exact wording | Status | Conf. | Evidence basis | Limitation |
|---|---|---|---|---|---|
| **GM-1** | **Where players, opponents and the ball begin changes what happens in the first moments of play. Those effects are described by SPACE, NUMBERS, TIME and DIRECTION, not by a separate lever.** | **SUPPORTED** (acute) + taxonomy decision | M | Dyad studies: initial distance, field location, posture, angular co-positioning (SP-1); boundary analysis §5 | Acute research tasks; small samples; decay of influence unmeasured |
| **GM-2** | **Coaches choose which game moments players practise (e.g., turnover, kickout, loose ball, settled or unsettled defence) and how often. This decides which problems players meet. ## 21. Final taxonomic verdict

### **B — FREEZE GAME MOMENT (renamed from INITIAL STATE), classified as a different type of practice-design decision, not a constraint lever**

**Why not A (freeze as Lever 06 alongside SPACE–SCORING):**
- It does not modify the task. It selects the task and its frequency.
- Placing it in the constraint family would misdescribe it.

**Why not C (absorb):**
- Configuration **is** absorbed (§5).
- But **choosing which moment, and how often**, is a real, universal coaching decision that no frozen lever describes.
- McKay, tactical periodisation, FA transition guidance and AFL stoppages all show coaches making it deliberately.
- Absorbing it would hide it.

**Why not D (replace with GAME-MOMENT SAMPLING):**
- "Sampling" names only the frequency component.
- "GAME MOMENT" covers selection **and** frequency with a plainer name.

**Why not E:** the evidence permits a clear structural decision, even though its learning effects are UNKNOWN.

**Frozen definition (one sentence):**

> **GAME MOMENT is the coach's choice of which situation of the game a practice episode begins from, such as a turnover, kickout, loose ball, or settled or unsettled defence, and how often each situation is practised.**

**Mapping of everything else:**

| Former component | Destination |
|---|---|
| Player / ball locations, width, depth, distances | SPACE |
| Local overloads, advantage starts | NUMBERS |
| Pressure distance, delayed / recovering entries | TIME |
| Proximity to target; polarity after natural turnover | DIRECTION |
| Coach-called vs game-generated moment (signal source); initial orientation; score-time scenarios | INFORMATION (provisional; re-examine at its audit) |
| Fixed positional assignments that persist | PLAYER ROLES / RULES (future) |
| Supplied vs recognised vs created | **Cross-framework principle CF-1** |
| Predictability / variation of configuration | INFORMATION (unpredictability) × GAME MOMENT (repetition); effects UNKNOWN |

## 22. Framework implication

**What six audits now suggest a coach can actually manipulate** (PÁIRCVISION INTERPRETATION; not a product architecture):

1. **Task constraints: properties of the problem inside an episode.**
   - SPACE, NUMBERS, TIME, DIRECTION (structural) and SCORING (evaluative; SCORING gate §24).
   - Likely later: RULES and CONSEQUENCES.
2. **Task selection and exposure: which problems are practised, how often, and in what order.**
   - GAME MOMENT.
   - Probably also the sequencing logic of EXPOSE → EXPLORE → RELEASE → RETAIN (a scheduling / observation hypothesis, not a constraint).
3. **Coach control of information and agency: what the coach supplies versus what players must detect or create.**
   - Called moments, cues, instructions, visible rewards, placed positions.
   - Largely the territory of **INFORMATION**, plus the cross-framework principle **CF-1**.

**Conclusion.**
- We are discovering **multiple families of practice-design decisions**, not one family of ten parallel levers.
- The original ten-item list **mixed** task constraints (SPACE, NUMBERS, TIME, DIRECTION, SCORING) with a task-selection decision (STARTING POSITIONS → GAME MOMENT).
- PLAYER ROLES, RULES, INFORMATION and CONSEQUENCES should each be audited with that question in mind: **constraint, selection, or control?**
- **Conceptual honesty beats taxonomic symmetry.**
