# PáircVision Phase 1 — Lever 05: SCORING — Scientific Audit

**Type:** Scientific evidence audit. Research only: no drills, sessions, UI, product features or production code.
**Frozen context (V1):**
- [SPACE gate](./phase1-lever-01-space-final-gate.md)
- [NUMBERS gate](./phase1-lever-02-numbers-final-gate.md)
- [TIME gate](./phase1-lever-03-time-final-gate.md)
- [DIRECTION gate](./phase1-lever-04-direction-final-gate.md)

The DIRECTION gate left the DIRECTION / SCORING boundary provisional (its §2). This audit is where that boundary is tested.
**Status:** v1 audit, September 2026. **Companion:** [SCORING practitioner & cross-sport audit](./phase1-lever-05-scoring-practitioner-audit.md). Superseded in part by the [SCORING Final Evidence & Falsification Gate](./phase1-lever-05-scoring-final-gate.md). **Where either audit and the final gate differ, the final gate governs PáircVision V1.** Notable gate changes: SCORING narrowed to assigned value (validity conditions → RULES; competition, score state and consequences moved out); SCO-1–SCO-9 reduced to four frozen principles (SC-1–SC-4); "rewarded behaviour ≠ learned behaviour" reworded to avoid implying non-learning; the zero-point boundary corrected.

> **Central questions (kept separate):**
> 1. What happens when a coach changes what is rewarded in a practice game?
> 2. Does rewarding a behaviour help players learn **when and why** it is useful, or does it only make them do more of it **while the reward exists**?
>
> **The distinction that matters most:** did the scoring system make the behaviour valuable, or did the player learn **why** it is valuable? Those are not the same thing.
>
> **Standing rules:**
> - More behaviour ≠ better behaviour ≠ learning ≠ transfer.
> - Practice behaviour ≠ learning.
> - **Corrected four-lever conclusion (DIRECTION gate §18):** we have far more evidence about how practice manipulations change behaviour *during* practice than about what players learn from them.

## 0. Method, access and evidence markers

### 0.1 Searches

Targeted searches (September 2026) covered:
- scoring manipulations in soccer, basketball and futsal small-sided games (SSGs): bonus points, conditional scoring, regain points, pass-based scoring, possession rewards;
- competitive vs non-competitive practice;
- removal, retention and transfer after scoring manipulations;
- real-competition scoring changes (soccer's 3 points for a win, rugby bonus points, basketball 3-point and 3x3 values, NFL fourth-down and conversion decisions, rugby penalty decisions, AFL and Gaelic shot models);
- the Gaelic football two-point score (rules and 2025–26 analyses);
- hurling scoring and 2026 trials;
- reward, competition and motivation meta-analyses;
- loss-framing research.

### 0.2 Access

- The egress proxy **refused** Frontiers, PubMed, PMC, SAGE, T&F, gaa.ie documents and university repositories (as in the DIRECTION gate).
- **No FULL TEXT was read.**
- **AO** = abstract wording via the search index.
- **SIO** = search-index summary only.
- **UNR** = unresolved detail.

### 0.3 Labels

- SUPPORTED · PARTIALLY SUPPORTED · CONTRADICTED · UNKNOWN · PRACTITIONER HEURISTIC · PÁIRCVISION HYPOTHESIS.
- Confidence: H / M / L / VL.
- **A / L / T** = acute / learning / transfer.

### 0.4 Honest headline

1. **Very few practice studies manipulate scoring as such.** Most "rule" studies manipulate restrictions (touch limits, pass counts, offside) or target form (DIRECTION).
2. **We found no invasion-sport study** that rewards a behaviour, then removes the reward and tests whether the behaviour stays.
3. The **strongest evidence that value changes behaviour comes from real competitions** (league points, shot values). It is observational or natural-experimental, with adults and professionals. It is **not practice-design evidence**.
4. **Gaelic two-point evidence is entirely descriptive** (2025–26). It is confounded by the other rule changes introduced at the same time.

## 2. Defining SCORING

### 2.1 Candidate

> *SCORING manipulates which outcomes or actions have value within the practice and how much relative value they carry.*

### 2.2 Test against manipulations

| Manipulation | Is it SCORING? | Reason / better home |
|---|---|---|
| Normal match scoring (goal 3, point 1, two-pointer 2) | **SCORING (baseline)** | The default value structure |
| Bonus points (score after a switch = +1) | **SCORING** | Changes relative value; the alternative stays legal |
| Weighted scores (wide score = 2) | **SCORING** | Relative value |
| Conditional scoring where the base score **still counts** ("1 point; 2 if all attackers are past halfway") | **SCORING** | Value varies by condition |
| Conditional scoring where the score **only** counts if X ("goal counts only if all attackers are in the attacking half") | **RULES** (compulsion expressed as scoring) | A zero value for the alternative makes X mandatory for scoring |
| Scoring zone where scores only count from inside the zone | **RULES × SPACE** | As above |
| Scoring zone worth more (score from zone = 2) | **SCORING × SPACE** | Relative value by location |
| End-zone scores (carry or receive over a line) | **DIRECTION** (target form) | Frozen in the DIRECTION gate |
| Double goals / multiple targets of **equal** value | **DIRECTION** (target number) | Frozen |
| Multiple targets of **unequal** value | **DIRECTION × SCORING** | Structure = DIRECTION; values = SCORING |
| Points for passes / N passes = 1 point | **SCORING (process)**. In a keep-ball game it defines the *only* objective, so DIRECTION's "zero" condition plus SCORING | — |
| "N passes before you may shoot" | **RULES** | Mandatory prerequisite |
| Points for line breaks, regains, switches, particular shot locations | **SCORING (process)** | Value attached to intermediate actions |
| Rewards for consecutive actions (escalating) | **SCORING (process, escalating)** | — |
| Penalties / lost points (turnover = −1) | **SCORING (negative value)** | — |
| Keep possession after scoring (basketball "point-possession") | **CONSEQUENCES** | What happens next, not a point value (§20) |
| Turnover → opponent attacks immediately | **CONSEQUENCES** | Structural outcome |
| Whether a score is kept at all; competition between teams | **SCORING** (presence of value) × **INFORMATION** (score visibility). Post-game stakes (losers collect cones) = **CONSEQUENCES** | §17 |
| Individual vs team rewards | **SCORING** (to whom value accrues) | A distinct dimension |
| Current score state ("you're 2 down, 3 minutes left") | **INFORMATION × SCORING × TIME** (parked) | §18 |

### 2.3 Verdict: **COHERENT WITH NARROWER DEFINITION** (PÁIRCVISION HYPOTHESIS, taxonomy)

> **SCORING is the value structure of a practice: which outcomes or actions earn or cost points, how much relative to each other, and to whom (team or individual), provided the unrewarded alternatives remain legal.**

**Boundary rule.** When a condition reduces an alternative's value to **zero** (the score does not count unless X), it functions as a **RULE**, whatever it is called.

**Not SCORING:**
- target presence, number, form and location (DIRECTION);
- mandatory or forbidden actions (RULES);
- what physically happens next (CONSEQUENCES);
- score visibility and score-state scenarios (INFORMATION interactions, parked).

**Resolution of the DIRECTION gate's provisional boundary.** Value manipulations (goal / point / two-point, route bonuses) belong to SCORING. SCORING **is retained** as a lever for now. Whether it survives independently depends on §3 and on the future CONSEQUENCES and INFORMATION audits.

## 3. SCORE vs RULE

**Example:**
- **RULE:** "You MUST switch before scoring." This removes the option of scoring without a switch.
- **SCORE:** "A score after a switch is worth double." Scoring without a switch remains legal, but is worth relatively less.

**Candidate:** *Rules alter what players are allowed or required to do. Scoring alters what players are incentivised to do.*

### 3.1 Evidence

| Question | Evidence | Status |
|---|---|---|
| Head-to-head comparison of a compulsory rule vs a bonus for the same behaviour | **None found** | UNKNOWN |
| Compulsory prerequisites change behaviour | "N passes before shooting" → more passes and possession maintenance; 2-touch → more direct play (*Front Psychol* 2019, 10:1554; review summary; AO / SIO) | SUPPORTED (acute) |
| Compulsion reduces exploration | More rule manipulations ↓ exploratory behaviour (*Front Psychol* 2019; AO). Mandatory positional zones ↓ co-adaptation (Gonçalves et al., 2017; SPACE gate) | PARTIALLY SUPPORTED (acute, restrictions generally) |
| Value-based rewards change behaviour | Basketball pass-graded scoring (value depends on passes made) ↑ perceived exertion (PLOS ONE 2024/25; AO). Regain bonus in U-20 soccer changed team spatial behaviour (Frontiers 2024; AO; see §4) | PARTIALLY SUPPORTED (acute) |
| Rewarded behaviour vs compelled behaviour: differences in exploration, decisions, retention | Not measured | UNKNOWN |

### 3.2 Edge cases where the distinction breaks down

1. **Zero-value conditions.** "Only counts if…" is a rule wearing scoring clothes (§2.2).
2. **Dominant bonuses.** If the bonus is large enough that the unrewarded option is almost never worth taking, the "option" is nominal. The bonus becomes a **de facto rule**. The threshold is **UNKNOWN** (§7).
3. **Severe penalties.** A large negative value for an action (e.g., −3 for a back pass) is a **de facto prohibition**.
4. **Social signalling.** A bonus announced by the coach also tells players *what the coach wants*. Players, especially children, may treat it as an instruction regardless of value. The bonus then acts partly through INFORMATION or instruction, not only incentive. (PÁIRCVISION HYPOTHESIS; the U-20 study in §4 found an *explicit* regain rule changed behaviour more than free play.)
5. **Score state.** In a real match, when behind by two late on, the two-point option can become effectively the only sensible one. Real scoring can be just as coercive as a practice bonus.
6. **Rules that shape incentives.** Many rules also change value indirectly (offside changes which runs pay off). The categories overlap at the margin.

### 3.3 Verdict

**PÁIRCVISION HYPOTHESIS (conceptually sound; not empirically tested).**
- The distinction is **useful for design description**: it asks "is the alternative still legal and still worth something?"
- It is **not yet shown** to matter for behaviour, exploration, decisions or learning.
- It **holds only while the unrewarded alternative remains genuinely competitive in value.**

## 5. The incentive problem

If a coach awards 2 points for X and X increases, four interpretations are possible:

| | Interpretation | What would distinguish it | Evidence |
|---|---|---|---|
| A | Players learned X (when and how it helps) | X appears **appropriately** after the bonus is removed, in a later reference game | **None** |
| B | Players learned "X is rewarded here" | X persists briefly after removal, then decays; or persists indiscriminately (including when inappropriate) | **None** |
| C | Players complied with the incentive | X drops back to baseline as soon as the bonus is removed | **None** |
| D | The reward redirected attention or perception and *may* create learning | Changes in what players look at or anticipate that persist after removal | **Indirect:** an explicit regain rule changed collective spatial behaviour acutely (§4 #2). **Learning untested** |

**Search for removal designs** (immediate removal, delayed retention, unconstrained reference games, match transfer, competition behaviour) for **scoring** manipulations: **none found**.
- The only reference-game study in the frozen gates (Gonzalez-Artetxe et al., 2023) used artificial *rules*, not scoring. It found little average change.
- **Does rewarded behaviour remain once the reward is removed? UNKNOWN.**
- A, B, C and D **cannot currently be distinguished**. Seeing X increase is compatible with all four.

## 6. Reward vs compulsion

**Emerging principle (SPACE gate P7, PARTIALLY SUPPORTED, indirect):** *make the desired behaviour useful rather than compulsory.*

| Design | Example | Evidence for exploration | Decisions | Tactical behaviour | Retention | Transfer |
|---|---|---|---|---|---|---|
| **Compulsory** | Must switch before scoring | More rule manipulations ↓ exploration; zones ↓ co-adaptation (acute) | Not measured | Changes acutely (pass-count → possession) | UNKNOWN | UNKNOWN |
| **Rewarded** | Bonus for a score after a switch | Not measured | Not measured | Regain bonus changed spatial behaviour (acute) | UNKNOWN | UNKNOWN |
| **Naturally useful** | Area, numbers and target placement make the switch the best route | Consistent with representative-design theory; SPACE / NUMBERS acute effects | Not measured | SPACE and DIRECTION acute effects | UNKNOWN | UNKNOWN |
| **Unrestricted play** | Normal game | Baseline. Free play produced more individual actions than instruction (*RQES* 2024) | Not measured | — | Gonzalez-Artetxe: free play vs rules showed little average difference in a reference match | UNKNOWN |

**Head-to-head evidence** comparing compulsory, rewarded and naturally useful designs for the **same** behaviour: **none**.

**Verdict:**
- No design is shown superior for exploration, decisions, tactical behaviour, retention or transfer.
- SPACE P7 **stands** as PARTIALLY SUPPORTED (indirect). SCORING adds **no new direct support**.
- The "useful rather than compulsory" logic places a bonus **between** compulsion and natural usefulness: the option is still legal, but the value is artificial. **PÁIRCVISION HYPOTHESIS.**

## 7. Reward magnitude

| Question | Evidence |
|---|---|
| Graded comparisons (1 vs 2 vs 3 points; small vs large; escalating) in practice | **None found** |
| Magnitude in real competition | **Soccer 3 points for a win** (win value 2 → 3): Moschini (2010; 35 countries, 1978–2007; AO) reported more goals in ~66 % and fewer draws in ~69 % of countries. **Garicano & Palacios-Huerta** (Spain; difference-in-differences vs cup games; AO) found **no net change in goals or draws**, but **more "sabotage"** (destructive / dirty play). Varela-Quintana, del Corral & Prieto-Rodríguez (2018) studied home-team responses (AO, detail UNR). **Mixed; side effects documented** |
| Value **ratio** changes shot selection | 3x3 vs 5v5 basketball, 2019 World Cups (*IJERPH* 2022, 19(22):15137; AO): values 1 / 2 vs 2 / 3, so the long-to-close value ratio is larger in 3x3. **Shot selection differed** between formats; efficiency patterns differed (exact figures UNR) |

**When does a reward distort the game?**

**UNKNOWN empirically.** The logical threshold:
- when the bonus makes the rewarded option **dominant** across nearly all situations, players have no reason to judge whether it fits the situation;
- the bonus has then become a de facto rule (§3.2).

**Evidence of gaming, unnatural behaviour or excessive risk in practice:**
- **none located** in SSG research;
- **in competition:** increased sabotage under stronger win incentives (Garicano & Palacios-Huerta; AO), and defensive adaptation eroding the value of the incentivised shot (NBA 3-pointer, §10).

**Do not assume a stronger incentive is a better teaching tool.** No evidence supports it. Competition evidence shows stronger incentives can produce **unintended** behaviour.

## 8. Rewarding outcome vs process

| | Outcome reward | Process reward |
|---|---|---|
| Examples | Goal, point, score, win | Line break, switch, N passes, regain, width, target-player involvement |
| What it rewards | The real objective | An intermediate action the coach believes leads to the objective |

**What process scoring might do (reasoning, not evidence):**
- make an important behaviour visible and salient;
- increase opportunities to practise it;
- focus attention.

**What it might also do (reasoning):**
- replace the real objective ("chasing points");
- reward the action when it is inappropriate;
- remove the need to judge whether the action helped.
- The general version of this concern is **Goodhart's law** (economics / management: a measure that becomes a target stops being a good measure). This is **not sport evidence**.

**Evidence:**
- The regain bonus (§4 #2) is the only located process-scoring study. It changed collective spatial behaviour acutely. It **did not measure** whether regains were attempted appropriately.
- The basketball pass-graded scoring raised perceived exertion; no decision data.

**Status:**
- **Process scoring changes acute behaviour: PARTIALLY SUPPORTED** (one or two studies).
- **Every benefit and every risk listed above is PÁIRCVISION HYPOTHESIS** until tested.

**Link to DIRECTION DIR-3 (frozen).** Progress can only be judged relative to the target and the defence's state. A process bonus that pays for the **action** (switch, line break) rather than its **effect** is structurally blind to that context.

## 9. Scoring and decision-making

| Question | Evidence | Status |
|---|---|---|
| Does altered scoring in practice change decision **quality**? | No located scoring study measured decision quality. The U-20 study measured spatial and coordination metrics. The basketball study measured load and enjoyment | **UNKNOWN** |
| Does it change **choice**? | Competition: yes. Value ratio changes shot selection (3x3 vs 5v5); expected-value logic drove the NBA shift to 3-pointers (analytics sources; SIO) | **SUPPORTED** (competition, cross-sport) |
| Do decision-makers choose value-maximising options? | **Not reliably.** Romer (2006, *J Polit Econ*): NFL teams far more conservative on fourth down than a dynamic-programming model recommends. Yam & Lopez (2019, *J Quant Anal Sports*): a causal estimate that more aggression would gain ≈ 0.4 wins per season (AO / SIO) | **SUPPORTED** (NFL coaches, professional) |

**Critical distinction.**
- **Changing the decision players make does not show that decision-making improved.**
- If a bonus makes players shoot from wide, their *choices* changed. Whether those choices were **better** depends on the real game's values, not the practice's.

**Operationalisation warning.** Most SSG "decision-making" measures rate choices against **the game's own rules**. With altered scoring, the "correct" decision is defined by the **artificial** value system. A player who correctly exploits a bonus may score as a "good decision-maker" in a way that would be a poor decision under real scoring. (Same structural caveat as the DIRECTION gate §4.2.)

## 10. Scoring and risk

**Observational evidence from real competition** (not practice experiments):

| Sport | Value structure | What changed or was found | Access |
|---|---|---|---|
| **Basketball** | 2 vs 3 points | Long-run shift from mid-range to 3-pointers driven by expected points. A Syracuse analysis (2024 report) found the 3-pointer's average expected value fell **below** the 2-pointer's from 2017–18, attributed to defensive adaptation | SIO (university news report; primary UNR) |
| **3x3 basketball** | 1 vs 2 points | Different shot selection from 5v5 at the same event level | AO |
| **Soccer (league)** | 2 → 3 points per win | Mixed: more goals and fewer draws in many countries (Moschini); no net change plus more sabotage in Spain (Garicano & Palacios-Huerta) | AO |
| **American football** | TD 6 (+1 / +2), FG 3 | Coaches systematically under-take risk on fourth down relative to models (Romer 2006; Yam & Lopez 2019) | AO / SIO |
| **Rugby union** | Try 5 (+2), penalty goal 3 | An expected-points framework maps where kicking for goal vs kicking to touch maximises expected return, by field location, metres gained and team strength (arXiv 2512.00312, 2025; **preprint**) | SIO |
| **Rugby union** | League bonus points (4 tries; losing by ≤ 7) | **No located study** of their effect on try-scoring behaviour | UNKNOWN |
| **AFL** | Goal 6, behind 1 | Shot accuracy depends on distance, angle and set vs open play (*JSAMS* 2024; AO). Expected-score models exist | AO |
| **Gaelic football** | Goal 3, point 1, two-pointer 2 (2025+) | Pre-2025 shot models (§12). 2025–26 descriptive shifts toward two-point attempts | AO / SIO |

**Experimental evidence manipulating point values in practice** to study risk (shot selection, passing risk, territorial risk, aggression, retention, defensive behaviour, end-game strategy): **none found**.

**What competition evidence permits:**
1. Changing value changes what players and teams **choose** (SUPPORTED, cross-sport).
2. The **net** effect on the intended outcome can be small or offset by side effects (sabotage; defensive adaptation).
3. Decision-makers **do not automatically** choose the value-maximising option (NFL).

**It does not show that practising with altered values teaches risk judgement.**

## 11. Multiple ways to score

**Evidence:**
- In competition, players respond to **value ratios** (3x3 vs 5v5) and to expected value over time (NBA; Gaelic two-pointer adoption).
- Multiple *targets* in practice change spread but did not improve decisions (DIRECTION gate §10). That was about target number, not value.

**Do players learn value, risk, context, score-state awareness or shot selection from multiple-value practice games? UNKNOWN.** No practice study found.

**Or do they simply optimise the artificial points system?**
- **Plausible** (PÁIRCVISION HYPOTHESIS).
- Practice value systems rarely match real success probabilities. The real value of a Gaelic two-point attempt depends on distance, pressure and the shooter (§12). A practice bonus for "long shots" ignores all three.

**Key arithmetic (not evidence, but a check any analysis must pass).** An option worth *v* points with success probability *p* has expected value *v × p*.
- A two-point attempt is worth more in expectation than a one-point attempt only if its success probability is **more than half** that of the one-point attempt.
- A three-point goal attempt beats a point attempt only if its success probability exceeds **one third** of the point attempt's.
- Continuation matters too: rebounds, 45s / 65s, possession after a miss.
- Practice bonuses that ignore probability teach a **different** value calculus from competition.

**Implication for PáircVision (hypothesis).**
- Gaelic football now has a **native three-tier value structure** with different success probabilities by distance and pressure.
- Real competition therefore already poses the value-and-risk problem that practice bonuses try to create artificially.
- A practice game with normal Gaelic scoring may carry more representative value information than an invented bonus.

## 13. Hurling

- **Current senior scoring:** goal = 3, point = 1.
  - Most scores are points; scoring range is very long.
  - No two-point score in senior hurling as of September 2026.
- **2026 trials** (Hurling Expert Advisory Group interim report, trials in the Fitzgibbon Cup league from mid-October 2026):
  - a **converted sideline cut worth two points**;
  - puck-outs must cross the 45 m line;
  - a ban on two consecutive hand-passes;
  - six steps;
  - 65s moved back.
  - These are 24 trial amendments, **not law** (RTÉ, Irish News, HoganStand; SIO).
  - The sideline-cut change is itself a **scoring-value manipulation designed to change behaviour**, with its evaluation still to come.
- **Evidence on hurling shot selection, goal-vs-point decisions and shot distance: no located peer-reviewed study.**
  - Journalism ("hurlers play the percentages"; Irish Examiner) and puckout retention research exist (DIRECTION practitioner audit; *IJPAS* 2025).
- **What hurling can teach (PÁIRCVISION INTERPRETATION):**
  - When point probability is high from long range, the goal chance must be very good to be worth more in expectation (the ⅓ arithmetic, §11).
  - Hurling is a natural case of choosing between a **high-probability low-value** and a **low-probability high-value** outcome.
  - **Do not transfer football findings directly.** Scoring range, ball and skill differ.

## 16. Negative scoring / penalties

- **Sport practice evidence** (losing points for turnovers, back passes or conceding certain outcomes): **none found. UNKNOWN.**
- **Broader psychology (flagged; do not import uncritically):**
  - loss vs gain framing changes risk-taking in some lab and field settings:
    - an NFL field study linked gain / loss frames to rule-breaking (*Judgment and Decision Making*, 2017; SIO);
    - a 2025 tennis study examined framing, competitive state and time pressure on risk decisions (SIO);
  - effects are **context- and role-dependent** (the NFL study found opposite directions for offensive and defensive players, SIO).
- **Whether negative scoring in practice creates caution, risk aversion, reduced exploration, anxiety, better execution or distorted behaviour: UNKNOWN.**
- **Logical concern (PÁIRCVISION HYPOTHESIS):** a penalty for an action (e.g., back passes) that is sometimes correct (DIRECTION DIR-3) punishes good decisions. That conflicts with the frozen SPACE heuristic P8.

## 17. Competition itself

**Proposition:** *SCORING is not only what earns points; the existence of a score may itself change the environment.*

| Evidence | Finding | Status |
|---|---|---|
| Direct SSG comparison: same game, score kept vs not kept | **Not located** | UNKNOWN |
| Rules tied to scoring chances may raise motivation and intensity | Hill-Haas et al. (2010): authors' interpretation, not measured | Speculation |
| Possession reward after scoring ↑ load and enjoyment | Basketball (§4 #1) | Acute; this is a **consequence**, not score presence |
| Coach verbal encouragement ↑ HR, RPE, enjoyment and technical measures | Youth basketball SSGs (*Front Psychol* 2025; AO) | Acute; social environment, not scoring |
| Competition and performance generally | **Murayama & Elliot (2012)** meta-analysis (*Psychol Bull*): **no noteworthy overall relation**. Competition raises performance-approach goals (helpful) and performance-avoidance goals (harmful), which offset | SUPPORTED (general psychology; not sport-practice-specific) |
| Youth score-keeping and enjoyment | Advocacy on both sides. One study reportedly found outcome did not directly affect children's experience when adults de-emphasised results (SIO; source UNR) | UNVERIFIED |

**Verdict.**
- That keeping score changes the practice environment is **plausible** (intensity, attention, pressure).
- It is **directly untested** in SSG research we could access.
- "Competition improves learning": **UNKNOWN**. General psychology suggests **no reliable net effect** on performance, with individual differences driven by the goals competition evokes.

## 18. Score state

- **Scoring system** (what things are worth) ≠ **score state** (where the game stands).
- The same environment can be solved differently at +1, −1, "need a goal" or "protect a lead".
- **Evidence:**
  - Soccer match-analysis literature widely reports match status effects on possession and tactics (e.g., teams behind tend to hold more possession). **Not re-verified in this audit (UNR).**
  - NFL decision research is inherently score- and time-state dependent (§9).
- **Gaelic: no located study** on score-state behaviour under two-point scoring.
- **Taxonomy (not forced; parked):**
  - score state is **game information** (INFORMATION) interacting with **values** (SCORING) and **time remaining** (TIME);
  - a coach-imposed scenario ("two down, three minutes left") manipulates all three;
  - re-check at the INFORMATION audit.

## 19. INFORMATION × SCORING (parked)

- To respond to scoring, players need to know:
  - the current score;
  - time remaining;
  - the value of each option;
  - sometimes which action earned a reward.
- **PÁIRCVISION HYPOTHESIS:** part of SCORING's effect is informational. It tells players what is valued (and, socially, what the coach wants: §3.2 edge case 4).
- The U-20 study's "explicit" vs "implicit" contrast (§4 #2) sits exactly on this boundary.
- **Explicitly parked for re-checking during the INFORMATION audit.**

## 20. CONSEQUENCES × SCORING

**Candidate distinction:**
- **SCORING** = symbolic / game value attached to outcomes (turnover = opponent +1).
- **CONSEQUENCES** = what physically or structurally happens next (turnover = opponent attacks immediately).

**Test:**
- The basketball offensive-reward study is a clean example. Rewarding a score with **another possession** (a consequence) produced a **distinct acute profile** (↑ pace and load, ↑ enjoyment) compared with normal scoring.
- A point value cannot produce that directly, because the consequence changes what the game *does next*.
- Many coach designs combine both (score = +1 **and** keep the ball).

**Verdict: DISTINCT AND USEFUL** (PÁIRCVISION HYPOTHESIS, taxonomy; one acute supporting example).
- CONSEQUENCES is **not** made redundant by SCORING.
- CONSEQUENCES has not yet been audited. The boundary is **provisional**.

## 26. Counterintuitive findings (sourced only)

1. **A stronger win incentive produced no net increase in goals, but more "sabotage"** (Spain, 3 points for a win; Garicano & Palacios-Huerta; AO). Other countries showed more goals (Moschini, 2010). The same incentive gave different results in different settings.
2. **The incentivised shot lost value as defences adapted.** The NBA 3-pointer's average expected value fell below the 2-pointer's from 2017–18 (Syracuse report; SIO).
3. **Professional decision-makers under-take favourable risk.** NFL coaches were far more conservative than expected-value models recommend (Romer, 2006; Yam & Lopez, 2019).
4. **Changing the value ratio changed shot selection** between 3x3 and 5v5 at the same World Cup level (*IJERPH* 2022).
5. **The highest-load rule was not the highest-effort rule.** In youth basketball, possession-reward games produced the highest external load and were more enjoyable than normal games, while the pass-graded scoring game produced the highest perceived exertion (*PLOS ONE* 2024/25).
6. **Constraints alone did not produce cooperative play.** In youth soccer, prescriptive instruction (alone or combined) was associated with better-connected passing networks, while free play or constraints without instruction were associated with more individual actions (*RQES* 2024).
7. **In pre-2025 Gaelic football, set-piece and open-play shots differed sharply in success:** frees ≈ 75 % vs open play ≈ 50% (2019; AO). The "same" point carries very different probabilities.
8. **Under high pressure, a Gaelic shot's success resembled one taken ≈ 9 m further out** (2019 model; AO). Value depends on pressure, not only distance.
9. **Gaelic championship scoring jumped ~12 points per game after 2025** (Kearney & Barrett; SIO). It cannot be attributed to the two-point score alone, because several rules changed at once.

## 29. Ten unanswered questions

1. When a bonus is removed, does the rewarded behaviour stay, disappear, or persist indiscriminately (including when it is wrong)?
2. Does a bonus teach players **when** an action is appropriate, or only **that** it pays?
3. For the same target behaviour, how do a compulsory rule, a bonus, and a "naturally useful" set-up compare on exploration, decisions, retention and transfer?
4. How big can a bonus be before players chase it regardless of the situation?
5. Does practising with real Gaelic values (goal / point / two-pointer) improve shot selection in matches more than practising with invented bonuses or none?
6. Can young players learn value × probability ("a harder shot worth more isn't always better"), and at what age?
7. Does keeping score change what players attempt (risk, creativity) compared with the same game unscored?
8. Do negative scores (losing points for turnovers) make players safer, better, or just more anxious and less exploratory?
9. How do Gaelic defences re-prioritise between the arc and the D, and can that be practised?
10. Do process bonuses (points for line breaks, regains) improve the real outcome (scores for, scores against) in a later normal game?

## 30. Volunteer coach translation (U12 Gaelic)

> **Changing the points changes what players chase.** If a score after a switch counts double, you'll see more switches. If a turnover wins a point, you'll see more pressing. That's reliable enough.
>
> **Seeing more of it doesn't mean they've learned it.** They might just be chasing your bonus. The test is whether they make that choice at the right times when the bonus is gone, next week, in a normal game. Nobody has shown that bonuses pass that test.
>
> **A bonus can bend the game.** If the switch bonus is big, players will switch even when the ball should go straight through. Then they're learning to please the scoring, not to read the game.
>
> **Normal scoring may be exactly what you need.** Our game already has a goal, a point and a two-pointer. Each is worth different amounts and is harder or easier depending on distance and pressure. Playing with the real scoring already asks players to weigh value against risk.
>
> **What to watch besides the scoreboard:**
> - Did they go for the bonus **when it made sense**, or every time?
> - Did anything else go missing: shots, runs, patience?
> - Did defenders change what they protect?
> - When you go back to normal scoring, what's still there?

| **SCO-1** | Changing what is rewarded changes what players choose | **PARTIALLY SUPPORTED:** strong in competition (cross-sport), thin in practice (acute; one or two studies) | M (competition) / L (practice) | "Change what's worth points and players change what they go for. That's well shown in real competitions, and in a few practice studies." |
| **SCO-2** | Rewarded behaviour ≠ learned behaviour | **SUPPORTED** (as an evidence-status statement: no removal, retention or transfer study) | M | "More of the rewarded action while the bonus is on tells you nothing yet about whether players learned when to use it." |
| **SCO-3** | Score ≠ rule, but only while the alternative stays genuinely worth taking | **PÁIRCVISION HYPOTHESIS** (conceptual; untested); edge cases in §3.2 | L | "A bonus keeps the other options legal; a rule removes them. A very big bonus, or a score that only counts if X, is really a rule." |
| **SCO-4** | Value means nothing without probability | **SUPPORTED** (arithmetic + competition shot models); practice implications **PÁIRCVISION HYPOTHESIS** | M | "A bigger score isn't a better choice unless it's likely enough. A two-pointer beats a point attempt only if it goes over more than half as often." |
| **SCO-5** | Incentives create side effects, including unintended behaviour and opposition adaptation | **PARTIALLY SUPPORTED** (competition natural experiments; mixed) | L–M | "Rewards can produce behaviour nobody intended, and opponents adapt to whatever is rewarded." |
| **SCO-6** | Process scoring rewards the visible action, not its appropriateness | **PÁIRCVISION HYPOTHESIS** (logical; consistent with DIRECTION DIR-3) | L | "Paying for a switch pays for switching, not for switching at the right moment." |
| **SCO-7** | Keeping score changes the environment; its effect on learning is unknown | **UNKNOWN** (learning); competition has no reliable net performance effect in general psychology | L | "Keeping score changes the feel of a game. Whether it helps players learn isn't known, and competition doesn't help everyone." |
| **SCO-8** | Gaelic football already has a three-tier value structure with probability that depends on distance and pressure | **SUPPORTED** (rules; pre-2025 shot models) / practice implication **PÁIRCVISION HYPOTHESIS** | M (structure) / L (implication) | "Goal, point and two-pointer already ask players to weigh value against risk. Invented bonuses may teach a different sum." |
| **SCO-9** | SCORING and CONSEQUENCES are distinct manipulations | **PÁIRCVISION HYPOTHESIS** (taxonomy; one acute example) | L | "Giving points is different from changing what happens next, like keeping the ball after a score." |

**Removed before candidacy:**
- "Bonus scoring is better than rules": no evidence.
- "Bigger rewards teach faster": no evidence.
- "Competition motivates": contradicted as universal.
