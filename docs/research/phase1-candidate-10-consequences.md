> **Central question.** After an action or outcome in practice, what happens next, and does deliberately changing what follows create a distinct practice-design property not already explained by the framework?
>
> **Critical standard:** EVENT → IMMEDIATE FOLLOW-UP → BEHAVIOUR DURING PRACTICE → LEARNING → RETENTION → TRANSFER, kept separate.
>
> **Boundary under test:** SCORING owns **changing the value of what happened**. Does anything distinct own **changing what happens next**?
>
> **This is the last of the original ten candidates. It is not preserved for symmetry.**

---

## 0. Honest headline

1. **"Consequence" names at least four unrelated things:** the unfolding game (natural consequences), coach-made follow-ups (bonus attackers, retained possession), behaviour-management sanctions (running, push-ups, benching) and learning-theory contingencies (reinforcement, punishment, error).
2. **Every coach-made follow-up tested classifies under an existing lever.** "After a turnover, +1 attacker" is NUMBERS; "after a score, keep the ball" is GAME MOMENT (the next episode's start) or DIRECTION; "after a miss, reverse direction" is DIRECTION; "after a regain, 6-second clock" is TIME.
3. **What remains is not a property but a pattern:** any lever can be **activated by an event**. That is a descriptor (*event-contingent*), not a new lever.
4. **Continuity vs reset** (does play carry on through a turnover or stop?) is the strongest residue. It decides **which follow-up moments players meet**, which is already GAME MOMENT's job (GM-2), plus DIRECTION's polarity rule.
5. **Punishments and external rewards sit outside practice design.** Punitive practices are associated with harm to youth developmental needs (qualitative); tangible expected rewards undermine free-choice intrinsic motivation in lab studies (contested meta-analysis). No learning benefit is shown.
6. **Transition learning evidence: none located.** Acute data only (continuous vs intermittent SSGs; field size and transition frequency). Gaelic match analysis shows turnovers are central to scoring, which is a **reason to practise transitions**, not evidence **how**.
7. **Provisional verdict (§38): C** — CONSEQUENCES dissolves into **conditional activation of existing levers**; continuity is flagged for the gate.

## 1. Defining "consequence"

| Meaning | Tradition | What it is | Same category as the others? |
|---|---|---|---|
| **Natural game consequence** | Invasion-game structure | What the game does next (turnover → defend) | The game itself |
| **Coach-created consequence** | Practice design | A modified follow-up (turnover → opposition +1) | Implements a lever |
| **Task consequence** | Task design | Any change in task state after an event | Generic |
| **Contingent consequence** | Behaviour analysis | Something delivered **contingent** on behaviour | Mechanism, not content |
| **Reinforcement** | Operant learning | Consequence that **increases** behaviour frequency | Functional definition (defined by effect) |
| **Punishment** | Operant learning | Consequence that **decreases** behaviour frequency | Functional; includes sport sanctions |
| **Reward** | Motivation (SDT) | Something given for engagement / performance | External to the game unless points |
| **Response cost** | Behaviour analysis | Loss of something (points, time, player) after behaviour | Could be SCORING or NUMBERS |
| **Error consequence** | Motor learning | What follows an error (feedback, task failure) | Feedback / task |
| **Outcome consequence** | Game | What an outcome produces (score → restart) | Natural game |
| **Next-state consequence** | Game / task design | The state that follows an event | Could be GAME MOMENT |
| **Possession consequence** | Invasion games | Who has the ball next | Game structure / DIRECTION polarity |
| **Restart consequence** | Invasion games | How play restarts (kickout, throw-up) | GAME MOMENT (sport-fixed restarts) |

**Finding.** Behavioural-psychology "consequences" (defined by their effect on behaviour frequency) and invasion-game "what happens next" (defined by the next game state) are **different concepts**. They should **not** share a category.

## 2. Natural game consequences

| Event | What naturally follows |
|---|---|
| Turnover | Losing team must defend at once; roles, direction, space and numbers flip |
| Regain | Winning team can attack an unsettled defence |
| Missed shot | Opponent restart (kickout / puckout) or possession |
| Score | Restart (kickout) |
| Failed press | Space behind the press; opponent may attack it |
| Defender steps out | Space opens elsewhere |
| Forward run | Space changes behind the runner |

- These are **the unfolding game**, not something the coach sets.
- The frozen framework already describes their ingredients: DIRECTION (polarity reverses on turnover), SPACE, NUMBERS, TIME, GAME MOMENT (restarts are sport-fixed moments).
- **Decision:** natural consequences **need no taxonomy category**. They are what a practice that **lets play continue** contains.

## 3. Coach-created consequences: what each actually changes

| Coach-created follow-up | Property actually changed |
|---|---|
| Turnover → opposition receives bonus attacker | **NUMBERS** (temporary) |
| Missed shot → shooter leaves temporarily | **NUMBERS** |
| Failed press → defence plays one down | **NUMBERS** |
| Score → scoring team keeps possession | **GAME MOMENT** (next episode starts with that team in possession) / DIRECTION polarity unchanged |
| Turnover → immediate shot opportunity | **GAME MOMENT** (a selected shooting moment) |
| Win ball → attack the opposite goal | **DIRECTION** (polarity rule) |
| Error → restart from a disadvantageous position | **GAME MOMENT** + **SPACE** (start location) |
| Regain → six-second clock | **TIME** |
| Score → smaller pitch | **SPACE** |
| Turnover → two points for scoring within 10 s | **SCORING** × TIME |
| Rule breach → free / penalty | Sport-authentic consequence (REFERENCE) or **GAME MOMENT** (set-piece start) |

**Every row has a primary home.** The only thing the rows share is the **trigger**: an event.

## 4. Kill test

**Question:** can two practices be identical in GAME MOMENT, SPACE, NUMBERS, TIME, DIRECTION, SCORING and ACTIONS, yet differ only in what happens after an event, with a material behavioural difference?

**Key subtlety:** "identical" must mean identical **specifications**. A practice where "+1 attacker after turnover" is specified **has** a different NUMBERS specification (a conditional one) from a practice without it. The question is whether the conditional part is something new.

See the **paired matrix (§31)**. Result:
- **In all ten pairs, the difference is describable** as a conditional specification of an existing lever, or as a GAME MOMENT / DIRECTION decision about how play continues.
- **Residue:** the **conditional form itself** (event → lever change) and the **continuity decision** (does play continue?). Neither is a new game property.

**Verdict: CONSEQUENCES fails the kill test as a property.** Whether "event-contingent" deserves a name as a **descriptor** is examined in §20–21.

## 5. "What happens next?"

**Candidate definition:** *CONSEQUENCES specifies how the practice changes after a defined action, event or outcome.*

| Test | Result |
|---|---|
| Distinct from GAME MOMENT? | **Partly.** GAME MOMENT chooses where an episode **begins**; a consequence determines what state **follows** within play. But a follow-up state **is** a moment: "after a score, the scoring team restarts with the ball" selects the next episode's start |
| Distinct from the levers? | **No.** The change after the event is always a change to space, numbers, time, direction, value, actions or starting moment |
| Adds anything? | The **timing** of a change (when in play it applies) and its **trigger** |

**Finding.** "What happens next" is a **useful question**, but the answer is always an existing property. It is **sequencing**, not a new property.

## 6. State transitions

- **Literature search:** transition rules and event-contingent task changes appear in **SSG design descriptions** (e.g., "8v8+4 defensive transition", "9v9+4 transition games") and in **tactical periodisation's game-moment model** (organised attack / defence, attacking / defensive transition), which is practitioner theory.
- **No formal state-machine framework** for practice design was found in sport science.
- **Is "state transition" more precise than "consequence"?** Yes, as a **description**: *event → next state*. But it describes **how GAME MOMENTS connect**, not a separate property.
- **Decision:** do **not** build a state-machine framework. Record *event → next state* as **GAME MOMENT sequencing language** (PÁIRCVISION SYNTHESIS).

## 7. Transition

**What changes on a possession change (natural):** team role, direction, available space, local numbers, urgency, tactical objective. That is **all six structural properties at once**, which is why transition is a distinctive game moment.

| Evidence | Finding | Level |
|---|---|---|
| Gaelic football, elite (*IJPAS* 2023, "A transition game?") | Almost **half of possessions originate from turnovers**; winning teams superior at securing and retaining possession | Match analysis (AO / SIO) |
| Gaelic football, sub-elite (*IJPAS* 2026) | Turnovers won **in contact** increase scoring likelihood; **1–10-pass** sequences more likely successful; advanced turnovers convert more (SIO; attribution between the two Gaelic papers **UNR**) | Match analysis |
| ">60 % of scores from turnovers" (Gaelic) | Circulating figure (practitioner / blog SIO) | **UNR**; not used as evidence |
| Tactical behaviour, youth soccer (PMC7706672) | **Larger fields → longer possessions, fewer transition phases** | Acute |
| Continuous vs intermittent SSGs (PMC12675327) | Continuous: better technical efficiency, fewer turnovers; higher enjoyment and RPE; **no tactical evidence on transitions** | Acute |

**Does letting turnovers unfold preserve a different problem from stop-and-reset?**
- **Logically, yes:** stop-and-reset removes the moment when the losing team is disorganised and the winning team faces an unsettled defence (GAME MOMENT gate; DIRECTION gate polarity).
- **Empirically:** **no study compares** transition-continuing vs stop-reset practice on transition behaviour, learning or transfer. **UNKNOWN.**

## 8. Continuity vs reset

| Format | What players meet after a turnover | Classification |
|---|---|---|
| Play continues | Natural transition (both teams) | **DIRECTION** polarity rule (reversal on turnover) + emergent GAME MOMENT |
| Whistle → reset | Nothing; new episode from the coach's chosen start | **GAME MOMENT** (episode ends; next start selected) |
| Coach feeds a new ball at once | A coach-supplied transition-like start | **GAME MOMENT** (selected transition) + coach signal (**GI-2**) |
| Predetermined counterattack (e.g., 3v2 the other way) | A scripted transition | **GAME MOMENT** + **NUMBERS** (given overload) |

**Evidence:** continuous vs intermittent SSG formats differ in load, technical efficiency and enjoyment (acute). **No transition-learning comparison.**

**Taxonomy home:** continuity is a decision about **which moments players meet and whether they emerge or are supplied**, i.e., **GAME MOMENT** (GM-2) with **DIRECTION** polarity. It is **more important in practice** than artificial rewards, but it is **not a new property**.

## 9. Possession after score

| Variant | Primary home | Secondary |
|---|---|---|
| Normal restart (kickout / puckout) | **REFERENCE** (sport rule) / GAME MOMENT (restart) | — |
| Scoring team keeps ball | **GAME MOMENT** (next episode's start: attacking team in possession) | SCORING-like incentive (keeping the ball has value) |
| Conceding team restarts from own end | **GAME MOMENT** + SPACE | — |
| Immediate second attack (wave) | **GAME MOMENT** (repetition of attacking starts) | TIME (no recovery) |
| Score triggers direction reversal | **DIRECTION** (polarity) | — |

**Primary + secondary reasoning holds.** No CONSEQUENCES home needed.

## 10. Bonus after event

| Variant | Home |
|---|---|
| 2 points for scoring after a turnover | **SCORING** (value, conditional on a preceding event) |
| Score after a turnover → another possession | **GAME MOMENT** (next start) — its **value** is implicit, so it also works like SCORING (expected-value equivalence; SCORING gate §19) |

**Finding.** The SCORING gate's provisional boundary holds: SCORING = value; "what happens next" = the next **state**. The second variant is a **state** change, but the state is a **GAME MOMENT**, not a new property.

## 11. Punishment

| Evidence | Finding | Level / access |
|---|---|---|
| **Battaglia et al. (2017)**, *J Appl Sport Psychol* | Youth hockey players (11–13, n = 12) reported punishments (benching, yelling, exercise, cleaning, positions); interpreted as **hindering developmental needs** (positive self, relationships) | Qualitative (AO) |
| Punishment and dropout (hockey) | Punishment experiences examined in decisions to cease participation (Battaglia et al.; SIO) | Qualitative (SIO) |
| **Exercise as punishment: coaches' perspectives** (*ISCJ* 2020; 8 university coaches) | Used frequently (push-ups, sprints) | Qualitative (AO) |
| Benching as behaviour management (*ISCJ* 2022) | Coach perspectives | Qualitative (SIO) |
| Advocacy claims (avoid mistakes rather than improve; anxiety) | Practitioner / media | **Opinion**, not evidence |
| Learning, decision-making or risk-taking effects of physical punishment for mistakes | **No experimental study located** | **UNKNOWN** |

**Finding.**
- **External punishment** (running, push-ups) does **not change the game problem**. It is **behaviour management**, outside practice design.
- **Evidence status:** associated with harm to youth developmental needs (qualitative); **no evidence** it improves learning; effects on risk-taking **UNKNOWN**.
- **Distinguish** from in-game "response costs" (lose a player, lose points), which change NUMBERS or SCORING and **do** change the problem.

## 12. Reward

- **Inside the game:** points and bonuses = **SCORING** (frozen).
- **Outside the game:** prizes, tokens, "winners skip the run" → **not practice design**.
- **Evidence:** Deci, Koestner & Ryan (1999) meta-analysis (128 studies): expected tangible rewards undermined free-choice intrinsic motivation (e.g., performance-contingent d ≈ −0.28); verbal, informational feedback can help. **Contested** (Cameron & Pierce). Lab tasks, not sport practice.
- **Competition outcome:** winning raised intrinsic motivation relative to losing (older lab study; SIO).
- **Decision:** external rewards sit **outside** the framework; motivation research is **not reopened** here.

---

## 13. Error consequences

| Evidence | Finding | Transfer to tactical invasion games |
|---|---|---|
| **Errorless learning** (Maxwell, Masters et al. 2001; golf putting) | Fewer errors in learning → more implicit learning; **robust under dual-task load** | Simple motor task; lab |
| **Errorless vs errorful meta-analysis** (2025/26; lifespan / impairment) | **No significant overall effect** | Motor tasks; clinical mix |
| **Error management training** (Keith & Frese 2008; 24 studies, N = 2,183) | Encouraging errors + exploration: **d ≈ 0.44**, larger for **transfer to structurally different tasks** | Workplace / software training, **not sport** |
| **Error augmentation** (reaching / visuomotor tasks) | Amplified error feedback can speed adaptation | Laboratory motor adaptation |

**Does manipulating what happens after error help learning?**
- **Motor:** mixed; errorless vs errorful shows no overall difference; error augmentation works in narrow lab tasks.
- **Cognitive / adaptive:** error-encouraging training helps transfer (non-sport).
- **Tactical invasion-game learning: UNKNOWN.** Transfer from these literatures is **not warranted**.

## 14. Error augmentation

- **What it is:** making a small error produce a larger visible or felt consequence.
- **Classification:**
  - amplified **feedback** about the error → **COACH INTERVENTION** (deferred; feedback);
  - a **task** change that makes errors costlier (e.g., smaller target, faster opponent restart) → the relevant **lever** (SPACE, TIME, NUMBERS, SCORING).
- **Relevance to Phase 1: low.** No new property.

## 16. CONSEQUENCES vs SCORING

**Candidate boundary:** *SCORING changes how outcomes are valued. A follow-up changes what state / play follows.*

| Example | Home |
|---|---|
| Bonus point | **SCORING** |
| Possession retained | **GAME MOMENT** (next start) |
| Extra attacker | **NUMBERS** |
| Immediate restart | **GAME MOMENT** / TIME (no recovery) |
| Reverse direction | **DIRECTION** |
| Player removed | **NUMBERS** |
| Shot opportunity | **GAME MOMENT** |
| Reset | **GAME MOMENT** (episode ends) |

**Boundary holds**, with one amendment: "what state follows" always resolves into an **existing** property. The SCORING gate's provisional "CONSEQUENCES" column should read **GAME MOMENT / NUMBERS / DIRECTION / SPACE / TIME** as appropriate.

## 17. CONSEQUENCES vs GAME MOMENT

- **Candidate:** GAME MOMENT selects where episodes begin; a consequence determines which situation follows an event.
- **Test:** every coach-made follow-up **selects the next situation**. "After a turnover, 3v2 the other way" is a **transition moment with a given overload**; it just starts **mid-play** instead of from a coach's feed.
- **Decision:** consequences are **sequencing logic for GAME MOMENT** (which moment follows which), not a separate property. GAME MOMENT's scope is **clarified**, not expanded: it covers moments that **start** episodes **and** moments that **follow** events when the coach specifies them.

---

## 18. CONSEQUENCES vs ACTIONS

**Example:** "after a turnover, the first pass must be a kick forward."
- The required kick → **ACTIONS**.
- The condition ("after a turnover") → the **trigger**.
- **CONSEQUENCES adds nothing** beyond the conditional form.

---

## 19. CONSEQUENCES vs NUMBERS

**Example:** "lose possession → one player must leave until you regain."
- NUMBERS changes (temporary, event-triggered).
- "After a turnover" is **the trigger activating NUMBERS**.
- **This is the decisive kill-test case.** If the trigger were a property, every lever would need a "consequence" twin. It is not; it is **when the lever applies**.

---

## 20. Conditional manipulations

| Conditional form | Lever | Continuous version |
|---|---|---|
| After turnover → +1 attacker | NUMBERS | Permanent +1 |
| After score → smaller space | SPACE | Permanently smaller |
| After miss → reverse direction | DIRECTION | Fixed direction |
| After three passes → target changes | DIRECTION | Fixed target |
| After regain → six-second clock | TIME | Always a clock |

**Is event-contingent fundamentally different from continuous?**
- **Yes, in three ways:**
  1. The change is **temporary** (a window: TIME).
  2. It is **linked to an event** players must notice (GI-2 applies if recognising the event is the objective).
  3. It creates **repeated state changes** (a practice with alternating conditions).
- **No, in kind:** the property changed is still the same lever.
- **Evidence:** no study compares contingent vs continuous versions of the same manipulation. **UNKNOWN.**

**Decision:** the framework needs the **concept** that *any lever can be activated by an event* (a **descriptor**), **not** a CONSEQUENCES lever.

## 21. Temporal sequencing: naming the residue

| Candidate name | What it would name | Verdict |
|---|---|---|
| CONSEQUENCES | Everything after an event | **Too broad**; mixes game, coach rules and sanctions |
| CONTINUITY | Whether play carries on through events | **Precise** for the continuity decision; belongs under GAME MOMENT |
| NEXT STATE | The state after an event | Accurate description; = GAME MOMENT sequencing |
| TRANSITIONS | Possession changes | A **game moment**, not a property |
| SEQUENCING | Order of moments | GAME MOMENT's scope |
| **EVENT-CONTINGENT** (descriptor) | A lever that applies only after an event | **Best descriptor** for coach-made follow-ups |
| Nothing | — | Viable if the gate prefers maximum economy |

**Literature:** "conditioned games" and "transition games" appear in SSG literature as **formats**; no literature treats event-contingency as a **design dimension**. **PÁIRCVISION SYNTHESIS.**

**Provisional:** use **event-contingent** as a descriptor on any lever; use **continuity** as a GAME MOMENT note. **Do not optimise the terms further before the gate.**

## 22. Representative consequences

**Hypothesis:** a practice may preserve the initial decision but distort what normally follows (e.g., a turnover game that stops when possession changes: players practise winning / losing the ball but not the immediate attack / defence).

| Test | Result |
|---|---|
| Logic | Sound: stopping removes the follow-up problem |
| Evidence | **None** comparing learning with and without the follow-up |
| Connection | Parallel to **GI-2** (information missing) and **GM-2** (which problems players meet) |
| Does it always matter? | **No.** Only when the **follow-up itself** is part of the objective (transition). If the objective is winning the ball, stopping may be fine |

**Status: PÁIRCVISION HYPOTHESIS**, conditional on objective.

## 23. Decision allocation

| Consequence rule | Supplied (lens) | Remaining |
|---|---|---|
| Turnover → coach gives attack 3v2 | **The overload** (WHAT situation), often **WHEN** | Recognising / exploiting the 3v2: who, when, how |
| Turnover → first pass must go forward | **WHAT** (the pass type) | WHO, WHEN, HOW |
| Score → scoring team keeps ball | **Who has possession** | Everything in the next episode |
| Regain → 6-second clock | A deadline | Route, who, how |
| Miss → shooter leaves | Numbers change | All decisions in the new numbers |
| Play continues naturally | Nothing | Recognising the transition, organising, exploiting |

**Finding:** consequence rules supply **what situation comes next** (and sometimes WHEN). They leave the decisions **within** that situation. DA-1 covers this unchanged.

## 24. CF-1 v2

- **Example:** every turnover automatically creates a 3v2. Success exploiting the 3v2 does **not** show players can **create** an overload; it may show they can **recognise and exploit** it (if not also called).
- **Already covered:** CF-1 v2 lists "an overload" and "a called moment" among supplied conditions.
- **Decision: no amendment.**

## 25. GI-2 / INFORMATION CHECK

| Case | GI-2 applies? |
|---|---|
| Coach whistle activates the counterattack | **Yes**: the signal replaces the turnover as the cue |
| Actual turnover activates the counterattack | Cue preserved |
| Play stops at turnover (reset) | Not an information issue: the **problem** (transition) is absent; that is **GAME MOMENT** (which moments are practised) |

**Does Candidate 10 add anything beyond GI-2?**
- **One distinction:** GI-2 covers a **missing cue** for a moment that still occurs. **Continuity** covers a **missing moment**: the follow-up never happens.
- The missing-moment case is already GAME MOMENT's territory (GM-2: coaches choose which moments players meet). A **note** is warranted, not a new principle (§35).

## 35. Candidate principles

| # | Wording | Evidence status | Conf. | Limitation |
|---|---|---|---|---|
| **CO-1** | **A coach-made follow-up to an event (extra player, retained ball, reversed direction, clock, point) changes an existing property of the practice: numbers, starting moment, direction, time, value or actions. ## 36. U12 volunteer translation

> **When something happens (a turnover, a miss, a score), ask: what would happen next in a real match?**
>
> **If you want them to get better at that next bit** (like switching straight to defence when they lose it), **let play carry on.** Don't blow the whistle.
>
> **If today is about something else** (like winning the ball in the first place), **stopping and restarting is fine.**
>
> **You can also make something happen on purpose,** like "if you win it back, you get an extra player for ten seconds." That's just changing the numbers for a while.
>
> **Leave out the push-ups and laps for mistakes.** They don't make anyone better at the game.

## 37. Simplicity gate

- **Researchers can describe event-contingent state changes. Coaches don't need a lever for them.**
- **Smallest useful distinction:** *"Do I let play carry on after it happens, or stop it?"* (continuity).
- It sits **inside** existing thinking: which moments players meet (GAME MOMENT), and *"What am I telling them, and what am I leaving them to solve?"* (a scripted follow-up tells them what situation comes next).
- **"What happens next?"** is a good **everyday** question; **not frozen**.
- **Terms that must not reach coaches:** event-contingent, state transition, response cost, reinforcement.

---

## 38. Taxonomy verdict

### **C — CONSEQUENCES dissolves into conditional activation of existing levers.** Continuity is flagged for the gate (D-leaning).

1. **Coach-made follow-ups** classify under the lever they change (NUMBERS, SPACE, TIME, DIRECTION, SCORING, ACTIONS, GAME MOMENT), with **event-contingent** as a descriptor (CO-1).
2. **Natural consequences** are the unfolding game; no category.
3. **Continuity vs reset** is a **GAME MOMENT** decision (which moments players meet, and whether follow-up moments are allowed to emerge), with DIRECTION's polarity rule (CO-2). **For the gate:** is a continuity **note** under GAME MOMENT enough, or does it need an internal check alongside GI-2 (option D)?
4. **Sanctions and external rewards** sit **outside** practice design (CO-3).

**Not A:** fails the kill test.
**Not B:** "continuity / next state" is GAME MOMENT sequencing, not a property.
**Not E as expansion:** GAME MOMENT's scope is **clarified** (moments that follow events when specified), not expanded into a state machine.
**Not F / G:** the picture is clear.

## 39. Architecture after Candidate 10 (provisional)

```
CHOOSE THE PROBLEM
  GAME MOMENT — which situations players meet, how often, and (clarified) whether
    follow-up moments are allowed to unfold or are reset / scripted

CHANGE THE PROBLEM
  SPACE · NUMBERS · TIME · DIRECTION · SCORING · ACTIONS
  (any of these may be event-contingent: applied only after a defined event)

CROSS-FRAMEWORK
  DECISION ALLOCATION · CF-1 v2 (unchanged) · GI-2 / INFORMATION CHECK
  candidate for the gate: continuity note (CO-2)

DEFERRED
  COACH INTERVENTION (feedback incl. error feedback / augmentation)

OUTSIDE PRACTICE DESIGN
  Sanctions and external rewards (behaviour management / motivation)

REFERENCE
  Official game / rules (incl. sport-fixed restarts and frees)
```

**What remains after Candidate 10:** no pending levers. The original ten have resolved into:
- **one selection decision** (GAME MOMENT);
- **six problem properties** (SPACE, NUMBERS, TIME, DIRECTION, SCORING, ACTIONS);
- **a cross-framework layer** (DECISION ALLOCATION, CF-1 v2, GI-2);
- **one deferred framework** (COACH INTERVENTION);
- **a reference** (the official game).

**No symmetry forced.**
